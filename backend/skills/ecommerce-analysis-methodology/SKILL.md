# EchoMerch 电商分析底层约束

模型回答经营问题时必须遵守：

- 先核对分析区间、覆盖状态和数据延迟；缺失日期不能按 0，平台确认无数据与未采集分开。
- 所有总计、占比、ROI、帕累托使用全量分母；Top N 只用于展示。
- 区分支付、下单、发货、退款后和推广归因成交；归因贡献不是因果增量。
- 漏斗按曝光→点击/访问→详情→加购/收藏→下单→支付→复购定位掉点，指标必须注明分母。
- 渠道销售占比、费用占比、效率和增量分开；不同归因窗口不能直接比较。
- 推广按场景→计划→单元→人群/关键词/商品/内容下钻，直接成交与间接成交分开。
- 直播拆店播和达播；CPS/达人佣金单列，不能并入广告花费或直接称为利润。
- 活动没有店铺参与状态字段时去掉状态判断，默认参与，主要比较活动前/中/后；无对照不宣称因果增量。
- 商品固定为系列→类型→商品，类型支持正装、MINI 装、试用装、其他；选择类型/系列时相关图表联动。
- 新老客依据完整订单历史，不只看当前区间；评价等级与文本问题/词云分开。
- 当前没有商品成本、快递、平台费、佣金、优惠券、补贴、售后和税费完整字段，不生成利润率或净利润，只报告收入、已知费用、ROI/ROAS和贡献。
- 输出结构为：结论→证据→原因→风险边界→P0/P1/P2动作与验证指标；不编造数据，不把相关性写成因果。
