# 市场洞察

本 Skill 用于把平台市场快照转成可验证的经营假设。先审计日期覆盖，再解释头部店铺、商品、内容和搜索需求，最后给出小范围验证动作。

## 数据边界

- `sycm_market_rankings` 是平台相对排行样本，不是本店支付金额、财务结算或利润。
- `sycm_market_keywords` 的热度、点击率和支付转化可能是区间值；保留原始区间，不反推精确 GMV。
- 缺失日期不能按 0 补齐。平台确认无数据和采集缺失必须分开。
- 没有实验、对照或平台增量报告时，只描述市场观察和归因信号，不声称因果增量。

## 分析顺序

1. 输出分析区间、最新市场日、排行/搜索词覆盖天数和缺失日期。
2. 观察头部店铺、商品、内容的排名和变化，形成竞品监控清单。
3. 按搜索词热度、点击率、支付转化区间和机会分筛选需求信号。
4. 先校验机会词与当前类目的相关性；跨类目噪声保留在原始证据，但不能生成标题、内容或投放建议。
5. 把相关机会词映射到本店商品、标题、详情、投放词包和库存准备，先小预算或小范围测试。
6. 给出验证指标：点击率、加购率、支付转化率、搜索流量、退款率和库存覆盖天数。

## 输出要求

固定包含：一句话结论、证据表、数据质量风险、置信度、P0/P1/P2 动作和验证指标。机会分只用于候选排序，必须经过类目相关性校验和本店实测；不要把平台排行直接写成店铺 GMV，也不要在数据不完整时给出确定性增长承诺。
