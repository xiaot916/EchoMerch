# 通用规划框架

以下规则来自用户提供的年度规划、618 框架和 618 活动方案，仅作为方法参考，不是 EchoMerch 的默认目标或品牌规则。

## 目标树

- GMV = UV x 支付转化率 x 客单价。
- 目标同时检查新客占比、会员/直播/CPS 等渠道结构、退款后的净 GMV 和费用率。
- 预算规划与盈利判断分开：目标 ROI 不是利润，毛利、佣金、服务费和退款影响缺失时不输出利润结论。

## 拆解层级

1. 活动总目标和周期。
2. 阶段：蓄水、预售/开门红、日销、高潮或用户自定义阶段。
3. 渠道：自然/付费、直播、CPS、会员、内容、补贴等，以目录真实字段为准。
4. 商品角色：引流款、主销款、利润款、新品/增长款、形象或内容款。
5. 每层输出金额、占比、前置条件、负责人和验证指标。

## 节奏和复盘

- 节点前看蓄水 UV、新客和加购；节点中看 CVR、ATV、支付和预算消耗；节点后看退款、净 GMV、毛利和复购。
- 日预算应回勾到阶段和总预算；阶段、渠道、商品占比合计需要接近 100%。
- 缺失日期不能当作 0。平台确认无数据要单独标注为 no_data。

## 618 目标与预算闸门

当用户给出“GMV 目标 + 预算 + 目标 ROI”时，至少同时输出：

```text
预算可承载归因 GMV = 预算 x 目标 ROI
非付费/重叠渠道承接 GMV = 总 GMV - 预算可承载归因 GMV
目标 UV = 总 GMV / (规划 CVR x 规划 ATV)
```

规划 CVR/ATV 未提供时，可以暂用最近 30 个业务日基线，但必须标注为情景假设。预算可承载归因 GMV 不等于店铺总 GMV；会员、直播、CPS、百补和内容可能与一级来源重叠，只能作为贡献标签验收。

建议阶段默认节奏为：蓄水 5%、启动/预售 20%、日销承接 30%、高潮 40%、返场/复盘 5%。这只是可调整的初始情景，活动日期、库存和历史峰值明确后应重新分配。
