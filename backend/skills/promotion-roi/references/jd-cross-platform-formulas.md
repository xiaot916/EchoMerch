# JD 参考口径与天猫映射

来源：`已解密_希杰JD投放日报0417.xlsx`。这份文件只作为公式和分析结构参考，不作为 EchoMerch 的运行时数据源。

## 可跨平台复用

| 业务口径 | 通用公式 | 天猫当前映射 |
| --- | --- | --- |
| CTR | 点击量 / 展现量 | `clicks / impressions` |
| CPC | 花费 / 点击量 | `spend / clicks` |
| 点击转化率 | 成交人数 / 点击量 | `buyers / clicks` |
| 加购率 | 总购物车数 / 点击量 | `carts / clicks` |
| 加购成本 | 花费 / 总购物车数 | `spend / carts` |
| 成交获客成本 | 花费 / 成交人数 | `spend / buyers` |
| 直接 ROI | 直接成交金额 / 花费 | `direct_gmv / spend` |
| 整体 ROI | 总成交金额 / 花费 | `gmv / spend` |
| 推广客单价 | 总成交金额 / 成交人数 | `gmv / buyers` |
| 新客成交占比 | 成交新客数 / 成交人数 | `new_buyers / buyers` |

## 需要保留的分析结构

1. 维度顺序：渠道/场景 -> 计划 -> 单元/人群/关键词 -> 商品。
2. 成交拆分：直接成交、间接成交、总成交不能合并后再解释。
3. 归因窗口：1 天和 15 天分别展示，不能用一个 ROI 代替另一个。
4. 成本判断：ROI 不是利润，预算动作还要结合商品毛利、佣金、服务费和退款。
5. 缺失语义：没有曝光或点击时，CTR/CPC/CVR 等指标为 `null`，不是 0；平台确认无数据和采集缺失分开。

## 当前天猫未直接迁移

- 预算消耗进度：天猫标准化库当前没有统一预算字段，暂不计算。
- 京东特有的站外、京速推、京选店铺等渠道：保留为平台适配层概念，不放入跨平台指标目录。
- `GETPIVOTDATA`、透视表引用和工作簿内 SKU 匹配表：转换为 MCP 的维度筛选和白名单聚合，不把 Excel 公式带入后端。
